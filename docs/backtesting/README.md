# Backtesting docs — index & report→script map

Everything backtesting-related lives here (`docs/backtesting/`); strategy theses live in
`docs/strategy/`; the durable decision log is `memory/decisions.md` (ADRs).

**Two kinds of file live in this folder — know which you're editing:**

1. **Script-generated reports** — written by a `*.py` via `write_text(...)`. **Re-running the
   script overwrites the file.** Where a report carries hand-added curated analysis (sub-period
   reads, ETF caveats, honest verdicts), that text is layered on top of the auto-output and a
   blind re-run will clobber it — re-add or use the script's own report template.
2. **Hand-authored docs** — design/spec/contract/runbook/memo/phase reports. No script emits
   them; edit them directly.

The pipeline: **`scripts/backtest/*.py` (or `scripts/paper/*.py`) reads `backtest-data/lake/…`
→ writes a `docs/backtesting/*-report.md`.**

| `delivery-spike-report.md` | `scripts/backtest/run_delivery_spike.py` | H4 delivery-spike event-drift study (event study + net per-trade + calendar portfolio; entry at close[t+1], no lookahead) |
